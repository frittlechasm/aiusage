# Context

## Glossary

- **Primary Codex limits**: The default Codex usage windows shown as the headline `5h` and `Weekly` bars.
- **Codex Spark limits**: Separate Codex 5.3 Spark usage windows shown under the Codex heading when selected with the canonical `codex-spark` slug or its `spark` alias. Selecting both `codex` and Spark merges them into one section backed by one usage fetch.
- **Banked resets**: Account-level Codex rate-limit resets saved for later use, shown as numbered supporting lines with every available expiry.
- **Extra credits**: Additional account-assigned usage credit shown only when available for the account.
